# Fixture Preparation

Do not ask the coding agent to invent benchmark evidence.

The human/editorial team must prepare and approve the five public-source evidence fixtures before the benchmark is considered valid.

Required fixture families:

1. Union Budget / government finance
2. Infrastructure data
3. Political claim-check with a mixed/qualified gold verdict
4. India geopolitics with uncertainty
5. Under-covered institutional/policy story

Every fixture must contain:
- frozen evidence excerpts;
- source IDs and metadata;
- an atomic claim for verification;
- accepted neutral research summary;
- locked claims for copy generation;
- a hidden human-approved gold section.

No model may browse during the static benchmark.
